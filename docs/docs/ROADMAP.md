# Production roadmap

The current package is a complete runnable foundation rather than a fake collection of empty files. Next production-hardening steps: Alembic migrations, Redis pub/sub for multi-instance WebSockets, S3 media storage, push notifications, 2FA, refresh-token rotation, moderation roles, channel broadcast semantics, voice/video WebRTC, E2E encryption, antivirus scanning, rate limiting, audit logs, backups and observability.
