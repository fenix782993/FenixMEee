# Fenix Messenger feature map

## Account
- register/login/logout
- JWT sessions
- profile name and bio
- online state

## Messaging
- private chats
- groups
- realtime WebSocket
- message history
- edit/delete
- pin
- reactions
- media URLs and uploads
- message search

## UI
- responsive desktop/mobile layout
- sidebar search
- people directory
- dark/light theme
- profile modal
- chat member panel
- Telegram-inspired visual language with original Fenix branding
