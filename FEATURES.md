# Fenix Messenger 4.0 — Feature Matrix

## Accounts
- username: 5–32 chars, latin/digits/underscore
- password hashing with Argon2
- JWT session
- profile avatar URL
- display name / bio
- online flag / last seen
- public 3/4 digit ID
- owner role

## Messaging
- private chats
- groups
- message history
- edit/delete
- pin
- reactions
- reply field in API
- favorites
- attachments
- image/file messages
- WebSocket updates

## Discovery
- username search
- display-name search
- 3/4 digit public ID search
- minimum 5 characters for textual user lookup in UI

## Media
- emoji catalog
- sticker catalog
- GIF endpoint
- upload API (25 MB per file)

## UI
- responsive desktop/mobile
- profile drawer
- owner panel
- dark/light theme
- chat list
- people list
- favorites
- message search
